# 安卓字母顺序点击脚本

在游戏字母页输入或粘贴 `abcd`，点击输入框的“确定”，3 秒后依次点击 A、B、C、D。每次只执行一遍。

支持多行批量粘贴，每行一组。例如：

```text
abcd
bdcd
```

先点击 A、B、C、D，最后一个 D 点击完成后等待设定时间（默认 10 秒），再点击 B、D、C、D。仅开始前倒计时 3 秒，最后一组结束后不再等待。等待期间也可以按音量上键停止，停止后不会继续下一组。

## 手机使用

使用 VS Code 的 Auto.js / AutoX 插件时，打开整个 `D:\script\mobile_input` 文件夹，连接手机后执行“保存项目到设备（Save Project）”。目录中的 `project.json` 已将入口指定为 `mobile_input.js`，插件会同步三个运行脚本；测试文件与手机压缩包不参与同步。保存后在手机上运行主脚本，或使用插件的运行项目命令。更新前先退出手机上正在运行的旧脚本。

1. 安装 AutoX.js，选择支持 Rhino 脚本和 XML 布局的版本。下载地址：https://github.com/autox-community/AutoX/releases 。本脚本不是浏览器脚本或独立 APK。
2. 将 `mobile_input.js`、`keymap.js` 和 `auto_coordinates.js` 一起复制到手机同一个文件夹。在 AutoX.js 中打开并运行 `mobile_input.js`。也可解压 `mobile_input_phone.zip`，使用里面的三个脚本。
3. 为 AutoX.js 开启无障碍服务和“显示在其他应用上层”权限。如果脚本跳转申请悬浮窗权限，授权后重新运行。
4. 切换到游戏，打开截图中的字母键盘页（2/2）。悬浮窗标题可以拖动。
5. 首次点击“自动识别坐标”，按安卓系统提示授权屏幕截图；如可选择范围，选择“整个屏幕”。保持游戏字母页可见，识别成功会提示并保存坐标。也可点击“手动校准”，依次轻触 **A、G、V** 的中心；校准触摸不会点击游戏。
6. 点击“输入 / 粘贴”后，悬浮菜单自动收起，只保留“展开菜单”按钮，避免遮挡输入框。输入文字，或长按输入框选择系统“粘贴”；需要时可展开/收起菜单，输入内容不受影响。确定或取消输入后自动恢复菜单；确定后进入执行面板，保留进度、“暂停 / 继续”和“停止”按钮，3 秒后执行点击。
7. 批量任务可直接点击 **停止**，在倒计时、点击、组间等待或暂停期间均有效；终止后回到输入面板，不再执行后续字符，也不能继续该批任务。已经开始的单次按压会完成，停止不撤销已发送的点击。**音量上键**仍可停止任务或取消校准；“退出”关闭脚本。
8. 批量执行时点击“暂停”，按钮变为“继续”；点击“继续”从原组、原字符进度接着执行，不重新开始。倒计时、字符间隔和组间等待都会冻结，继续后仅等待剩余时间。已经开始的单次按压（60 毫秒）会完成，不会重放。暂停期间按音量上键则终止整批，不能再继续。
9. 拖动标题可以移动执行面板。如果面板挡住待点击字母，脚本会自动暂停；拖开面板后点击“继续”。

## 输入和位置

- 自动识别针对所给截图的金色字体、7 列 4 行字母页，使用内置字形模板：定位 A、G、V 后至少核对 25 个按键形状和网格关系，校验通过才保存。支持一定范围内的缩放和位移；字体、皮肤、明显拉伸或遮挡变化可能导致失败。
- 自动识别时控制面板暂时隐藏，截图仅在手机内存中处理，不上传或保存截图。识别本身不会点击游戏。失败、取消或权限未通过均保留上次坐标，可继续手动校准；音量上键可以取消识别计算。

- 大小写均可，换行分组，空行跳过，行内空格自动去掉；支持 A–Z、`-`、`1`。开始前检查所有行，任何一行包含其他字符都会提示行号，整批不执行。
- 不限制输入长度，按完整文本依次点击，直到完成或按音量上键停止。脚本不清空已有输入，不翻页、不提交魔咒；执行前请保证游戏处于正确页面且输入位可用。
- 默认坐标按所给 1080×2400 截图的相对位置缩放。屏幕比例、黑边或游戏布局不同，请使用校准。
- 校准假设按键是截图中的 7 列、4 行均匀网格：`ABCDEFG / HIJKLMN / OPQRSTU / VWXYZ-1`。
- 点击间隔默认 250 毫秒，按压时长 60 毫秒。“设置”可调整间隔为 100–2000 毫秒或恢复默认坐标。
- “设置 → 组间等待时间”可设置每组之间的等待秒数，默认 10 秒，支持 0–3600 秒和小数（如 2.5）。设为 0 则不额外等待；修改后自动保存，重启脚本仍有效。此项与组内字符点击间隔分别设置。
- 游戏改变窗口大小、方向或布局后需要重新校准。脚本不会识别游戏画面或验证游戏是否接收了字符。
- 如无法粘贴，使用输入框长按菜单或输入法剪贴板；脚本不在后台主动读取剪贴板。
- 若游戏漏字，调大点击间隔。若完全不响应，检查无障碍服务；部分应用不接受无障碍模拟触摸。

## 手机调试模式

- 点击面板上的“调试：关”即可开启，也可以在“设置 → 调试模式”中切换。开关会保存，重启脚本后沿用；首次默认关闭。
- 日志直接显示在控制面板中，最新消息在最上方，可上下滑动查看最近 120 条记录。点击“收起日志”只隐藏日志区域，仍继续记录；“查看日志”重新展开。
- 点击“复制日志”可将当前保留的全部日志（最多 120 条，按时间从早到晚，含报错详情）复制到手机剪贴板，然后直接粘贴到聊天中发送。日志收起或调试关闭时也能复制已有记录；没有日志时会提示，且不会覆盖剪贴板。复制不会清空日志或暂停批量任务。
- 识别日志包括截图/屏幕尺寸、候选字形数量、A/G/V 候选数、网格匹配数量、整体相似度和保存的实际坐标。相似度是字形匹配分数，不是正确率或概率。
- 点击日志包括组号、字符序号、字符、目标坐标和按压时长；出现点击失败时另有报错。也会记录暂停、继续、停止、组间等待和完成事件。
- 报错包含原因及可获得的调用栈。调试关闭时仍保留本次运行中的错误记录，开启后可查看。日志仅保存在内存，退出脚本后清空，不自动写文件。
- 自动截图识别前整个控制面板（包括日志）会隐藏，成功、失败或取消后都会恢复。手动校准时也会隐藏面板。不要另外打开 AutoX 自带的控制台悬浮窗，否则外部窗口可能遮挡游戏。
- 展开日志可能增大面板面积；若遮住目标字符，脚本会按原有逻辑自动暂停，可收起日志或拖开面板后继续。

## 本地验证

电脑执行 `node keymap.test.js` 检查输入处理、批量控制和坐标映射；执行 `node auto_coordinates.test.js` 验证原截图提取的字形、缩放/位移、空画面、键盘不完整及取消识别。手机截图授权、悬浮窗、无障碍触摸与游戏接收效果需要在实际手机上验证。

执行 `node debug_mode.test.js`，通过模拟手机 API 验证日志开关、记录上限、点击坐标、截图前隐藏，以及授权/截图/识别失败后的恢复逻辑；此检查不代替手机端界面验证。

API 参考：[AutoX 悬浮窗](https://autox-community.github.io/AutoX_Docs/floaty.html)、[按键事件](https://autox-community.github.io/AutoX_Docs/events.html)。
